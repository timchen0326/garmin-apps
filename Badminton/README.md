# Badminton

Records heart rate, time and calories as a **Badminton** activity (FIT sport
64 "Racket", sub-sport 95). No score tracking.

## Controls

| Button | Before start | During session |
|---|---|---|
| START | Start session | Pause and open menu: Resume / Save / Discard |
| BACK | Exit app | Ignored, so a stray press can't end the session |

The main screen shows elapsed time, live heart rate and calories. After saving,
a summary shows time, average and max heart rate, and calories.

Everything this app records is standard activity data, so it shows in Garmin
Connect whether the app is sideloaded or installed from the store.
